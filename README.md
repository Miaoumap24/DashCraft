# DashCraft

A lightweight, colorful, real-time dashboard built with **Python** and **JavaScript** to monitor system resources (CPU, RAM) and your **Minecraft** server status in one place.

![License: AGPLv3](https://img.shields.io/badge/License-AGPLv3-blue.svg)
![Python](https://img.shields.io/badge/Python-3.8+-yellow.svg)
![FastAPI](https://img.shields.io/badge/FastAPI-0.100+-green.svg)

---

## Features

* **Real-time System Monitoring**: Dynamic tracking of CPU and RAM usage using WebSockets.
* **Minecraft Server Integration**: Live player count, maximum player limits, and ping latency.
* **Lightweight & Fast**: Built with FastAPI for high performance and low resource overhead.
* **Clean UI**: Modern, dark-themed dashboard with bright visual indicators.

---

## Tech Stack

* **Backend**: Python 3.8+, FastAPI, WebSockets, `psutil`, `mcstatus`
* **Frontend**: HTML5, CSS3, Modern JavaScript (Fetch/WebSockets)

---

## Prerequisites

Make sure you have Python 3.8 or higher installed on your machine.
